# Do Smart Tech — site institucional (beta)

Landing page de página única da Do Smart Tech: HTML5, CSS3 e JavaScript puro, sem build nem dependências.

- `index.html` — conteúdo, SEO (metadados, Open Graph, JSON-LD) e sprite de ícones
- `style.css` — estilos em BEM, mobile first, tokens em variáveis CSS
- `script.js` — menu, seção ativa, revelação ao rolar e links do WhatsApp (número em `WHATSAPP_NUMBER`)
- `assets/` — logos (SVG), símbolo, favicons e imagem de compartilhamento

Para publicar em hospedagem tradicional, basta enviar todos os arquivos. Se o domínio final mudar,
troque a URL `https://oromolloy.github.io/do-smart-tech/` no `<head>` do `index.html` (canonical, Open Graph e JSON-LD).
